# Social Networking Service

### Данное приложение дает возможность просмотра постов из сети Интернет, посещения профилей друзей, регистрации и сохранения постов локально в память устройства для просмотра оффлайн.

## Содержание

1. Технологии
2. Основные возможности
3. Использование


# Технологии
1. Язык: Swift
2. UI: UIKit
3. Аутентификация: KeychainSwift (сохранение email и пароля локально на устройстве), FirebaseAuth (сохранение email и пароля в Firebase)
4. База данных: CoreData (сохранение постов локально из сети Интернет в память устройства), FirebaseFirestore (сохранение данных пользователя при регистрации и считывание последних при входе)
5. Сеть: URLSession (отправка запросов на сервер)
6. Архитектура: Apple MVC

# Основные возможности
1. Регистрация
2. Авторизация
3. Просмотр постов из сети Интернет
4. Просмотр профилей друзей
5. Сохранение постов локально на устройство
