# Social Networking Service

### Данное приложение дает возможность просмотра постов из сети Интернет, посещения профилей друзей, регистрации и сохранения постов локально в память устройства для просмотра оффлайн.

# Технологии
### Язык: Swift
### UI: UIKit
### Аутентификация: KeychainSwift (сохранение email и пароля локально на устройстве), FirebaseAuth (сохранение email и пароля в Firebase)
### База данных: CoreData (сохранение постов локально из сети Интернет в память устройства), FirebaseFirestore (сохранение данных пользователя при регистрации и считывание последних при входе)
### Сеть: URLSession (отправка запросов на сервер)
### Архитектура: Apple MVC
